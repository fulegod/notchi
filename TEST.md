Notchi es una app de macOS que vive en el notch y reacciona en tiempo real a la actividad de Claude Code.
Detecta eventos (pensar, trabajar, errores, fin de sesión) mediante hooks que envían JSON por un socket Unix a una máquina de estados que controla sprites animados.
Analiza el sentimiento de tus prompts con la API de Anthropic para que la mascota muestre emociones (feliz, triste, neutral).
Soporta varias sesiones de Claude Code a la vez, cada una con su propio sprite, y al hacer clic expande un panel con actividad, info de sesión y uso de la API.
Requiere macOS 15.0+, una MacBook con notch y Claude Code instalado; se auto-actualiza vía Sparkle.
